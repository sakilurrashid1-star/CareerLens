# 🧠 CareerLens — Career Intelligence

**CareerLens** is an interactive, explainable career-intelligence dashboard that turns a user's current skills into practical career signals.

## ✨ Features

- 🎯 Role-fit scoring for Data Analyst, Data Scientist, ML Engineer, Full-Stack Developer and Cybersecurity Analyst
- 🧩 Interactive skill selection
- 📊 Explainable weighted scoring
- 🔎 Skill-gap analysis
- 📈 Illustrative salary, demand and remote-friendly signals
- 🗺️ Personalized three-step learning roadmap
- 💡 Decision guidance for what to do next
- 📱 Responsive premium dark UI
- ⚡ Zero backend and zero build step

## 🧮 Scoring

The portfolio demo uses a transparent scoring model rather than pretending to be a black-box AI system:

- 75% core-skill coverage
- 25% supporting-skill coverage
- Experience adjustment for Junior and Intermediate profiles
- Maximum displayed score: 99%

The market figures are **illustrative portfolio-demo benchmarks**, not live labor-market statistics.

## 🚀 Run locally

1. Clone the repository.
2. Open `index.html` in a modern browser.
3. Select a target role and toggle your skills.
4. Explore the role-fit score, skill gaps and roadmap.

## 🌐 GitHub Pages

Enable **Settings → Pages → Deploy from branch → main → / (root)** to publish the dashboard with GitHub Pages.
